### 🔍 探索方向 (Focus Areas)

* **多模态协同感知 (Cooperative Perception)**：研究无人机与地面车辆跨主体视角下的几何对齐、时序关联与鲁棒特征融合。
* **多源异构视觉感知 (Multimodal Sensing)**：融合可见光 (RGB)、红外热成像 (IR) 与深度 (Depth) 模态，提升全天候复杂场景检测鲁棒性。
* **自动驾驶与运筹调度 (Planning & Optimization)**：复杂交通路网拓扑调度、咽喉路权动态编排与高吞吐运力规划。
